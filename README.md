# ecomsac

Site vitrine e-commerce statique pour MAISON ÉLÉA. Ouvrir `index.html` localement pour prévisualiser le site.

Pour le premier déploiement, activer GitHub Pages dans [les paramètres Pages du dépôt](https://github.com/jadlm/ecomsac/settings/pages) en sélectionnant **GitHub Actions** comme source de publication. Ensuite, chaque push sur `main` déclenche le déploiement. Le site sera disponible sur https://jadlm.github.io/ecomsac/ après la réussite du workflow.

Les produits, prix, avis et coordonnées affichés sont des données fictives de démonstration.
